# One Line, Lights Out

> The lid clicks shut mid-sentence, and the charging light blinks once — the only thing left in the room still waiting.

`main.ts` validates the entry line — a single line of 1–199 characters with no newline or control characters — and writes it, with no trailing newline, to `entry.txt` inside the directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`). After writing, it reads the file back and confirms the contents are byte-exact before printing a short confirmation with the character count.
